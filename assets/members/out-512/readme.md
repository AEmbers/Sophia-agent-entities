## 四、关于「灵台主事 / 灵台郎 构图相近」——已决策：保持现状

**这两张的差异事实**（放大并排核对）：

| | 灵台主事（产品总监） | 灵台郎（系统架构师） |
| --- | --- | --- |
| 视线 | 仰头看左上方 | 平视偏前 |
| 星图 | 几何线框 | 放射星光 |
| 头饰 | 翡翠金簪 + 红流苏 | 仅额坠（无大簪） |
| 服饰主色 | 红白 | 黑金 |

即：**同属「侧身 + 星图 + 指点」这一个构图大类，但不是同一张**，四类特征均有区分。

**评估过「替换其中一张」的方案，结论是不做**：

尝试重新生成后得到的新图，与现有 19 张存在**画风割裂**（现有为浅色清新日系风；
新生成模型输出为深色厚涂星空风，且仅 1024 分辨率，标签样式也不同）。
单张替换会破坏整套素材的**统一性**，而统一性正是这类头像资产的主要价值。

**结论：保持现状。** 若后续确需拉开差异，正确做法是**整套 20 张一并重新生成**，
而不是替换单张——这样才能同时保住差分度与画风统一。

## 五、处理参数（可复现）

- 蒙版窗口：`x 27..2020` / `y 36..2029`（1994 × 1994 正方形）
- 圆角半径：370 px
- 边缘抗锯齿：1.5 px 线性过渡
- 512 降采样：HighQualityBicubic + HighQualityCompositing + HighQuality PixelOffset
- 为什么垂直方向不居中：原图内容（含底部职位标签）整体偏下，
  实测标签最下沿 y=2014；垂直居中会使下边界落在 y=2020，仅剩 6px 余量，视觉上标签贴边

原图未做任何改动，位于 `extracted/`，可随时对照。
